# Nagrik Nova - Backend Prototype

This is the local backend server for the Nagrik Nova hackathon project. It runs locally to bypass network/ISP blocks on cloud databases.

## ⚙️ Prerequisites for Frontend Devs
Before you can run this API on your machine, you **must** have MongoDB installed locally:
1. Download [MongoDB Community Server (Windows msi)](https://www.mongodb.com/try/download/community).
2. Run the installer and click **Next** until the "Service Configuration" screen.
3. **CRITICAL:** Make sure **"Install MongoDB as a Service"** is checked. This runs the database in the background automatically.
4. Finish the installation.
